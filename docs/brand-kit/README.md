# Dollyt brand kit

Les SVG sont ici :

- `dollyt-background.svg` : fond vectoriel 1920×1080 avec safelight, grain et vignette.
- `dollyt-button-presets.svg` : planche vectorielle des boutons, couleurs et tokens.

Les couleurs principales sont `#0A0807`, `#110E0C`, `#181411`, `#2B2420`,
`#3A322C`, `#E9E1D3`, `#9A8F83` et `#E03A1E`.

Polices : Instrument Sans pour l’interface et IBM Plex Mono pour les valeurs.
