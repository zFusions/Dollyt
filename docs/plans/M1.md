# Plan M1 — Moteur

**Objectif :** moteur fiable : binaires sous `%LOCALAPPDATA%\Dollyt\bin`, hash yt-dlp, sélection de format (preview + HQ), jobs avec progression et annulation, erreurs typées, logs sans secret.

**Spec :** [DESIGN.md](../DESIGN.md), [dollyt-engine](../../.cursor/skills/dollyt-engine/SKILL.md).

## Périmètre

| Inclus | Exclu (jalons suivants) |
|--------|-------------------------|
| `bins`, `process`, `format`, `jobs`, `settings` minimal | Presets produit, UI Chambre noire, mock `npm run dev` |
| Téléchargement yt-dlp (SHA-256) | ZIP FFmpeg auto (phase 1 : repli PATH → copie locale) |
| Progression ~10 Hz, annulation | Mise à jour yt-dlp au lancement |
| Logs rotatifs basiques | Installeur, CI release |

## Tâches

1. **bins + process** — chemins locaux, `ensure_tools` au démarrage, `Command` centralisé.
2. **format** — preview (itag 18 / muxé), HQ vidéo + audio (sans m3u8), tests fixtures.
3. **jobs** — file une tâche à la fois, events `job-progress` / `job-finished`, `cancel_job` tue l’arbre.
4. **logs** — `%LOCALAPPDATA%\Dollyt\logs`, pas d’URL signée.
5. **Clôture** — fmt, clippy, tests, note sécurité (URL, processus, chemins).
